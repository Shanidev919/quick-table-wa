# Spice Garden - WhatsApp Table Booking Website

A responsive restaurant website that allows customers to explore the menu and send table reservation enquiries directly via WhatsApp.

## Live Demo
👉 [View Live Website]( https://shanidev919.github.io/quick-table-wa/)

## Features
- Interactive food menu with pricing
- Direct WhatsApp table booking integration
- Mobile-friendly and clean user interface


## How It Works
1. Customer sends a booking request message on WhatsApp.
2. System checks availability and collects details (Date, Time, Guests).
3. Table is reserved and confirmation is sent back to the user.
